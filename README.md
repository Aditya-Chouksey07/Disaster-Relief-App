# Disaster Relief & Supply Chain Allocation Engine

A Java-based disaster relief management system designed to help organize emergency supplies and allocate them to relief camps based on **urgency and available inventory**.

The system uses a **custom PriorityQueue** to process camp requests in the order:

**CRITICAL → HIGH → MEDIUM → LOW**

It also provides a simple Java Swing dashboard for managing supplies, camp demands, resource allocation, and dispatch records.

## Features

### 🚨 Priority-Based Camp Requests

* Processes camp demands according to urgency.
* Uses a custom `PriorityQueue`.
* Critical requests are handled first.

### 📦 Inventory Management

* Maintains available stock for:

  * Medical
  * Food
  * Water
  * Shelter
* Automatically reduces inventory after allocation.
* Prevents allocating more supplies than available.

### 🖥️ Interactive GUI

* Built using **Java Swing**.
* Add new supplies through the GUI.
* Submit new camp demands dynamically.
* View inventory and active requests in a dual-pane dashboard.

### 🚚 Resource Allocation

* Automatically matches available supplies with camp demands.
* Supports full and partial allocation.
* Completed requests are removed from the queue.

### 📋 Dispatch Ledger

* Records completed allocations.
* Displays dispatch ID, camp, item, quantity, and timestamp.

### 📄 CSV Export

* Generates a `dispatch_manifest.csv` file.
* Useful for transport teams and record keeping.

* **Visual Studio Code**
* **Extension Pack for Java** for VS Code
* **Git**

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/DisasterReliefApp.git
```

### 2. Open the Project

```bash
cd DisasterReliefApp
code .
```

### 3. Run the Application

Open:

```text
src/com/relief/Main.java
```

Click **Run** in VS Code or press **F5**.

The Java Swing dashboard will open.

## How to Test

### 1. Check Initial Data

* Verify the dashboard displays the initial inventory.
* Check the number of active camp demands.
* Confirm that **CRITICAL** requests appear first.

### 2. Add Supplies

Click:

**+ Add New Donation/Supply**

Add a new item and quantity to the inventory.

### 3. Add Camp Demand

Click:

**+ Submit Camp Demand**

Enter the required camp, item, quantity, and urgency level.

### 4. Run Allocation Engine

Click:

**Run Allocation Engine**

Check that:

* Available stock decreases correctly.
* Completed requests are removed.
* Partially fulfilled requests remain.
* Dispatch records are added to the ledger.

### 5. Export Dispatch Manifest

Click:

**Export Manifest (CSV)**

The system creates:

```text
dispatch_manifest.csv
```

in the project directory.
